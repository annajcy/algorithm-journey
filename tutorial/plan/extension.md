# 扩展阶段

> [返回课程总览](overview.md)

## 阶段说明

| 项目 | 内容 |
| --- | --- |
| 适合人群 | 已完成入门和基础复习，准备首次系统学习 `扩展` 专题 |
| 主语言 | C++ |
| 内容范围 | 只覆盖 `099-153` 的 `扩展` 内容 |
| 前置要求 | 已掌握图论基础、DP 基础、树结构基础、数论基础 |
| 推荐学习方式 | 每周 2 节新课 + 1 次复盘/模板重写，优先理解专题为什么存在、模板怎么写 |
| 题目来源说明 | `src/` 中 Java 代码只作为题目来源和参考实现入口，讲解与模板全部使用 C++ |
| 建议节奏 | 16 周完成 |

## 每日 Codeforces 思维题训练

| 项目 | 内容 |
| --- | --- |
| 训练定位 | 偏 `结论转化 + 中等建模`，训练分类讨论、观察规律和思路落地 |
| 题目级别 | `Div2 C` 为主，少量入门 `Div2 D` |
| 每日题量 | 1 题为主，阶段性少量 2 题 |
| 建议限时 | 45-60 分钟 |
| 执行规则 | 先独立思考，再写关键思路，再编码，最后复盘；优先选和当前周字符串/树/DP/数论主线接近的题；每周至少挑 2 题做二刷，重点写出核心转折点而不是只保留代码；只在复盘周或状态好时，每周增加 1-2 天做第 2 题 |

### 课程 01：逆元、除法同余与容斥原理

- 学习目标：建立扩展阶段的数论工具基础
- 对应原课：099
- 知识点讲解（C++）：逆元定义、费马小定理求逆元、前缀逆元、容斥原理基本建模
- 题目来源（src Java）：`src/class099/Code01_InverseSingle.java`、`src/class099/Code02_InverseSerial.java`、`src/class099/Code04_NumberOfSubsetGcdK.java`
- C++ 模板：快速幂逆元模板、线性求逆元模板、容斥枚举模板
- 习题：做 2 道逆元题；做 1 道容斥入门题
- 复盘要点：先判模数条件，再决定逆元求法
- 完成标准：能写出单点逆元和线性逆元模板

### 课程 02：KMP 原理与常见题型

- 学习目标：掌握失配函数和模式串匹配主线
- 对应原课：100、101
- 知识点讲解（C++）：`next` 数组、失配跳转、最小循环节、删除重复匹配、树上/链表上的匹配
- 题目来源（src Java）：`src/class100/Code01_KMP.java`、`src/class101/Code01_RepeatMinimumLength.java`、`src/class101/Code02_DeleteAgainAndAgain.java`
- C++ 模板：KMP 模板、最小循环节模板
- 习题：做 2 道 KMP 基础题；做 1 道循环节题
- 复盘要点：KMP 的核心是“模式串自己帮自己跳”
- 完成标准：能独立手写 `next` 数组与匹配过程

### 课程 03：AC 自动机入门

- 学习目标：掌握多模式串匹配的基本框架
- 对应原课：102
- 知识点讲解（C++）：Trie 建树、fail 指针、BFS 建图、文本扫描、匹配统计
- 题目来源（src Java）：`src/class102/Code01_ACAM.java`、`src/class102/Code02_Counting.java`
- C++ 模板：AC 自动机模板、fail 树遍历模板
- 习题：手写 AC 自动机；做 1 道多模式匹配题
- 复盘要点：AC 自动机是 Trie + KMP fail 思想的结合
- 完成标准：能从零实现基础 AC 自动机
