# 课程总览

## 阶段说明

- 这是 `algorithm-journey` 的 C++ 课程门户，总共拆成 4 个阶段：`入门 -> 基础 -> 扩展 -> 挺难`
- `src/` 中的 Java 代码只作为题目来源和参考实现入口，不作为课程讲解语言
- 所有课程讲解、模板整理、解题表达统一使用 C++
- 当前阶段先提供结构化大纲，后续再逐课展开成正式教程

## 建议顺序

1. 先完成 [入门](intro.md)，恢复基础数据结构、基础算法和编码手感
2. 再完成 [基础](foundation.md)，系统复习 `必备` 阶段的主干专题
3. 然后进入 [扩展](extension.md)，学习此前没系统学过的中高级专题
4. 最后进入 [挺难](hard.md)，攻克高阶数据结构、离线算法和高级图论

## 建议节奏

| 阶段 | 目标 | 建议时长 |
| --- | --- | --- |
| 入门 | 恢复手感和基础代码能力 | 2 周 |
| 基础 | 搭建必备知识体系 | 6 周 |
| 扩展 | 首次系统学习进阶专题，并安排专题消化 | 16 周 |
| 挺难 | 建立高阶专题图谱，并留出综合题与模板重写时间 | 20 周 |

如果某周时间不够，优先保证：`知识点讲解 + C++ 模板 + 1~2 道代表题`。

## 每日 Codeforces 思维题训练

这条训练副线和课程主线并行执行：`每天固定 1 题`，目标是持续维持读题速度、思维强度和限时输出能力。

| 阶段 | 题目级别 | 每日题量 | 建议限时 | 训练重点 |
| --- | --- | --- | --- | --- |
| 入门 | `Div2 B` 偏简单 | 固定 1 题 | 25-35 分钟 | 恢复读题速度、基础构造、实现稳定性和边界意识 |
| 基础 | `Div2 B -> Div2 C` | 1 题为主，偶尔 2 题 | 35-45 分钟 | 建立题意到模型的映射能力，开始识别错判方向 |
| 扩展 | `Div2 C` 为主，少量入门 `Div2 D` | 1 题为主，阶段性少量 2 题 | 45-60 分钟 | 训练中等难度建模、分类讨论和结论转化 |
| 挺难 | `Div2 C/D` | 1 题为主，阶段性少量 2 题 | 60-90 分钟 | 训练抽象、构造、观察规律和多步推导能力 |

统一执行规则：

- 做题顺序：`先独立思考 -> 再写关键思路 -> 再编码 -> 最后复盘`
- 若超时未解：当天必须完成题解复盘，不把“未做完”拖到以后
- 长期默认 `1 题/天`；只有在复盘周、状态好、课程负担较轻时，才临时加到 `2 题`
- 若当天加做第 2 题，第 2 题优先选择同周主题下更轻或更典型的一题
- 选题原则：优先挑和当前阶段、当前周主线接近的题，尽量做到“同知识域”或“同思维方式”训练
- 这条训练是配套副线，不替代课程主线中的 `知识点讲解 + C++ 模板 + 代表题`

## 知识地图总览

| 阶段 | 主要知识域 | 你会重点遇到什么 |
| --- | --- | --- |
| 入门 | `基础编码`、`数据结构`、`树` | 基础模板、链表、栈队列、二分、树遍历 |
| 基础 | `数据结构`、`树`、`图论`、`DP`、`数论`、`字符串`、`综合复盘` | 必备主干专题、高频模板、题型识别 |
| 扩展 | `字符串`、`数据结构`、`树`、`DP`、`数论`、`图论` | 线段树、树上专题、DP 优化、组合与数论深化 |
| 挺难 | `数据结构`、`树`、`图论`、`离线算法/高级技巧`、`综合复盘` | 可持久化结构、离线分治、分块莫队、树分治、连通性分解 |
