# 挺难阶段

> [返回课程总览](overview.md)

## 阶段说明

| 项目 | 内容 |
| --- | --- |
| 适合人群 | 已完成入门、基础、扩展，准备首次系统学习 `挺难` 专题 |
| 主语言 | C++ |
| 内容范围 | 只覆盖 `154-194` 的 `挺难` 内容 |
| 前置要求 | 已掌握线段树、树上专题、离线思想、扩展数论与高级 DP |
| 推荐学习方式 | 每周 2 节新课 + 1 次复盘/模板重写，先理解结构和离线思想，再做综合题 |
| 题目来源说明 | `src/` 中 Java 代码只作为题目来源和参考实现入口，讲解与模板全部使用 C++ |
| 建议节奏 | 20 周完成 |

## 每日 Codeforces 思维题训练

| 项目 | 内容 |
| --- | --- |
| 训练定位 | 偏 `抽象能力 + 多步推导`，训练更难的构造、观察规律和复杂分类 |
| 题目级别 | `Div2 C/D` |
| 每日题量 | 1 题为主，阶段性少量 2 题 |
| 建议限时 | 60-90 分钟 |
| 执行规则 | 优先完整独立思考，再写关键思路，再编码，最后复盘；优先选和当前周高级数据结构/离线算法/树论/图论主线接近的题；若超时，也要先写自己的错误方向和正确突破口，再看题解；只在综合题消化周、课程较轻周或状态明显好时，少量加到 2 题 |

### 课程 01：左偏树基础

- 学习目标：掌握可并堆的基本结构
- 对应原课：154
- 知识点讲解（C++）：左偏树性质、合并操作、删除最值、并查集结合
- 题目来源（src Java）：`src/class154/Code01_LeftistTree1.java`、`src/class154/Code01_LeftistTree2.java`
- C++ 模板：左偏树模板、可并堆模板
- 习题：手写左偏树模板；做 1 道可并堆题
- 复盘要点：左偏树的核心是“合并优先”
- 完成标准：能独立写出 merge 主过程

### 课程 02：左偏树进阶与 k 短路背景

- 学习目标：继续理解堆上懒更新和更复杂的应用
- 对应原课：155
- 知识点讲解（C++）：懒标记可并堆、可持久化左偏树、k 短路问题中的堆结构
- 题目来源（src Java）：`src/class155/Code01_CityCapture1.java`、`src/class155/Code02_TrickyOperation1.java`
- C++ 模板：带懒更新左偏树模板
- 习题：做 1 道堆上懒更新题
- 复盘要点：复杂堆结构的难点在“信息何时下传”
- 完成标准：能说明左偏树比普通堆多解决了什么问题

### 课程 03：带权并查集

- 学习目标：掌握带相对关系的集合维护
- 对应原课：156
- 知识点讲解（C++）：带权并查集、距离/差值关系、矛盾检测、模意义关系维护
- 题目来源（src Java）：`src/class156/Code01_DerivePartialSums.java`、`src/class156/Code03_WrongAnswers.java`、`src/class156/Code04_LegendOfHeroes.java`
- C++ 模板：带权并查集模板
- 习题：做 2 道关系维护题
- 复盘要点：并查集节点到父亲的权值含义必须先定义清楚
- 完成标准：能独立推导路径压缩时权值如何更新
