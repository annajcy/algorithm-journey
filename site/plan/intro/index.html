    入门阶段¶

    返回课程总览

    阶段说明¶

    项目 内容
    适合人群 有算法竞赛基础，但基础知识点有遗忘
    主语言 C++
    内容范围 只覆盖 001-018 的 入门 内容
    前置要求 基本的 C++ 语法、数组、循环、函数
    推荐学习方式 先恢复模板和基础题感，再回收数据结构与遍历类基础题
    题目来源说明 src/ 中 Java 代码只作为题目来源，讲解与模板全部使用 C++
    练习策略 主线只做课内练习 + 每日 1 题 CF，不额外铺外部 OJ 题
    建议节奏 2 周完成，8 课 + 2 次机动复习

    每日 Codeforces 思维题训练¶

    项目 内容
    训练定位 偏 读题 + 实现 + 边界，用简单思维题把竞赛手感重新拉起来
    题目级别 Div2 B 偏简单
    每日题量 固定 1 题
    建议限时 25-35 分钟
    执行规则 先独立思考，再写关键思路，再编码，最后复盘；优先选和当周基础主题接近的题；若超时，最多再看 10 分钟，仍无思路就完成题解复盘并手写重做；这一阶段不建议常态化加到 2 题

    本阶段知识地图¶

    Week 知识域 训练类型 为什么这样排
    Week 1 基础编码、数据结构 模板课、结构原理 先恢复复杂度、位运算、排序、验证与二分等最基础的刷题动作
    Week 2 数据结构、树 结构原理、专题题 把链表、栈队列、二叉树遍历这些最常用结构重新串起来
    机动复习 综合复盘 复盘课 用模板默写和代表题重写把基础手感真正找回来

    每周课程主线之外，持续执行 每日 1 题 的 Codeforces 思维训练，且选题尽量贴合本周主题。

    Week 1¶

    知识域 训练类型 本周目标
    基础编码、数据结构 模板课、结构原理 恢复复杂度分析、位运算、排序、对拍和二分模板

    课程 01：算法学习框架与复杂度¶

    • 学习目标：建立复习主线，恢复复杂度分析和算法学习方法
    • 对应原课：001、002、007、008
    • 知识点讲解（C++）：时间复杂度、空间复杂度、常见数据规模与可行解法、C++ 刷题工程习惯
    • 配套代码（C++）：Language Conversion C++ 译写、Experiment C++ 译写、Complexity C++ 译写
    • C++ 模板：solve() 驱动模板、基础调试模板、复杂度速判 checklist
    • 习题：总结常见复杂度上界；写一份自己的竞赛/面试 C++ 基础模板
    • 复盘要点：先估复杂度，再定算法方向
    • 完成标准：能在 5 分钟内判断常见题目规模对应的可行复杂度
    • 正式讲义：Week 1 课程 01：算法学习框架与复杂度
    • 配套每日 CF：2064B - Variety is Discouraged

    课程 02：二进制与位运算入门¶

    • 学习目标：恢复二进制表示、补码、位运算基础性质
    • 对应原课：003
    • 知识点讲解（C++）：按位与/或/异或、移位、补码、lowbit、位运算常见误区
    • 题目来源（src Java）：src/class003/BinarySystem.java
    • C++ 模板：位运算工具函数模板、位枚举模板
    • 习题：补全常用位操作函数；做 2 道位运算基础题
    • 复盘要点：位运算先想性质，再写代码
    • 完成标准：能熟练解释异或、lowbit、补码的含义

    课程 03：基础排序¶

    • 学习目标：恢复选择、冒泡、插入排序及稳定性概念
    • 对应原课：004
    • 知识点讲解（C++）：三种基础排序、稳定性、交换成本与比较次数
    • 题目来源（src Java）：src/class004/SelectBubbleInsert.java
    • C++ 模板：选择排序、冒泡排序、插入排序模板
    • 习题：手写三种排序；比较适用场景
    • 复盘要点：基础排序主要用来训练循环控制和不变量
    • 完成标准：能独立写出三种排序并说明稳定性

    课程 04：对数器与验证习惯¶

    • 学习目标：重新建立“暴力 + 随机测试 + 对拍”的验证习惯
    • 对应原课：005
    • 知识点讲解（C++）：随机数据生成、暴力解构造、结果对拍、边界数据覆盖
    • 题目来源（src Java）：src/class005/Validator.java
    • C++ 模板：随机生成器模板、暴力对拍模板
    • 习题：为一个简单数组题写完整对数器
    • 复盘要点：复习阶段优先修复“会思路但代码不稳”
    • 完成标准：能对一个基础题完成自动化对拍

    课程 05：二分搜索与边界问题¶

    • 学习目标：恢复二分模板和边界控制
    • 对应原课：006
    • 知识点讲解（C++）：存在性二分、左/右边界、峰值、判定函数
    • 题目来源（src Java）：src/class006/Code01_FindNumber.java、src/class006/Code02_FindLeft.java、src/class006/Code03_FindRight.java、src/class006/Code04_FindPeakElement.java
    • C++ 模板：标准二分模板、左边界模板、右边界模板
    • 习题：手写 3 种二分模板；做 2 道边界查找题
    • 复盘要点：二分的核心是不变量，不是 while 写法
    • 完成标准：能不查资料写出 3 种标准二分

    Week 2¶

    知识域 训练类型 本周目标
    数据结构、树 结构原理、专题题 把链表、栈队列和二叉树遍历这些基础结构重新连成一个体系

    课程 06：链表基础与入门题¶

    • 学习目标：恢复链表基础操作和常见重连技巧
    • 对应原课：009、010、011、012
    • 知识点讲解（C++）：链表反转、合并有序链表、链表加法、链表划分、哑节点
    • 题目来源（src Java）：src/class009/ListReverse.java、src/class010/MergeTwoLists.java、src/class011/AddTwoNumbers.java、src/class012/PartitionList.java
    • C++ 模板：单链表节点模板、反转链表模板、合并链表模板
    • 习题：做 3 道链表基础题；复盘断链和重连顺序
    • 复盘要点：链表题先画指针变化图
    • 完成标准：能独立完成反转、合并、分段重连

    课程 07：栈、队列、双端队列¶

    • 学习目标：恢复线性结构的数组模拟能力
    • 对应原课：013、014、015、016
    • 知识点讲解（C++）：数组栈、循环队列、最小栈、双端队列、栈队列互相实现
    • 题目来源（src Java）：src/class013/QueueStackAndCircularQueue.java、src/class014/ConvertQueueAndStack.java、src/class015/GetMinStack.java、src/class016/CircularDeque.java
    • C++ 模板：数组栈模板、循环队列模板、双端队列模板、最小栈模板
    • 习题：手写 4 个结构；做 1 道结构设计题
    • 复盘要点：数组模拟是后续单调结构和图算法的基础
    • 完成标准：能不依赖 STL 写出正确的循环队列

    课程 08：二叉树遍历基础¶

    • 学习目标：恢复树遍历和递归/非递归等价视角
    • 对应原课：017、018
    • 知识点讲解（C++）：先中后序递归、显式栈模拟、层序遍历、复杂度分析
    • 题目来源（src Java）：src/class017/BinaryTreeTraversalRecursion.java、src/class018/BinaryTreeTraversalIteration.java
    • C++ 模板：递归遍历模板、非递归遍历模板、层序遍历模板
    • 习题：手写三序递归；手写前中后序非递归；做 2 道遍历题
    • 复盘要点：树遍历本质是访问时机控制
    • 完成标准：能独立写出三序递归和至少两种非递归遍历

    机动复习建议¶

    • 复习课 A：默写 fast io、二分、链表、栈队列模板
    • 复习课 B：从以上 8 课中任选 4 个代表题，全部用 C++ 重写一遍
