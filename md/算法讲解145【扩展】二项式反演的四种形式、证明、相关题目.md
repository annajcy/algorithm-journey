二项式系数的组合分解公式

这是二项式反演证明过程的重要一步

$$
{ \binom { j } { i } } { \binom { i } { n } } = { \binom { j } { n } } { \binom { j - n } { j - i } }
$$

# 代数证明：

从左边开始：

$$
{ \binom { j } { i } } { \binom { i } { n } } = { \frac { j ! } { i ! ( j - i ) ! } } \cdot { \frac { i ! } { n ! ( i - n ) ! } }
$$

化简后为：

$$
\frac { j ! } { n ! ( i - n ) ! ( j - i ) ! }
$$

这个结果已经化简为 ）·jn，现在我们来看右边的表达式。

右边：

$$
{ \binom { j } { n } } { \binom { j - n } { j - i } } = { \frac { j ! } { n ! { \bigl ( } j - n { \bigr ) } ! } } \cdot { \frac { ( j - n ) ! } { ( j - i ) ! ( i - n ) ! } }
$$

可以看到，右边也化简为：

$$
\frac { j ! } { n ! ( i - n ) ! ( j - i ) ! }
$$

因此，左右两边相等，证明了这个恒等式的正确性。

# 二项式反演的四种形式、证明、相关题目

形式一：

应用二项式系数恒等式：

$$
g ( n ) = \sum _ { i = 0 } ^ { n } ( - 1 ) ^ { i } { \binom { n } { i } } f ( i ) \iff f ( n ) = \sum _ { i = 0 } ^ { n } ( - 1 ) ^ { i } { \binom { n } { i } } g ( i )
$$

$$
{ \binom { n } { i } } { \binom { i } { j } } = { \binom { n } { j } } { \binom { n - j } { n - i } }
$$

证明：

从 $g ( n )$ 的定义开始：

将这个恒等式代入后， $f ( n )$ 化简为：

$$
g ( n ) = \sum _ { i = 0 } ^ { n } ( - 1 ) ^ { i } { \binom { n } { i } } f ( i )
$$

$$
f ( n ) = \sum _ { j = 0 } ^ { n } f ( j ) { \binom { n } { j } } \sum _ { i = j } ^ { n } ( - 1 ) ^ { i + j } { \binom { n - j } { n - i } }
$$

假设 $f ( n )$ 可以通过 $g ( i )$ 的线性组合表示：

$$
f ( n ) = \sum _ { i = 0 } ^ { n } ( - 1 ) ^ { i } { \binom { n } { i } } g ( i )
$$

现在，求和项 $\textstyle \sum _ { i = j } ^ { n } ( - 1 ) ^ { i + j } { \binom { n - j } { n - i } }$ 是 $( 1 - 1 ) ^ { n - j }$ ，即：

$$
( 1 - 1 ) ^ { n - j } = 0 \quad { \stackrel { * } { = } } \quad j \neq n
$$

将 $g ( i )$ 的定义代入 $f ( n )$

$$
f ( n ) = \sum _ { i = 0 } ^ { n } ( - 1 ) ^ { i } { \binom { n } { i } } \sum _ { j = 0 } ^ { i } ( - 1 ) ^ { j } { \binom { i } { j } } f ( j )
$$

当 $j = n$ 时， $( 1 - 1 ) ^ { 0 } = 1$

交换求和顺序，得到：

因此，最终我们得到 Kronecker delta 函数：

$$
f ( n ) = f ( n )
$$

$$
f ( n ) = \sum _ { j = 0 } ^ { n } f ( j ) \sum _ { i = j } ^ { n } ( - 1 ) ^ { i + j } { \binom { n } { i } } { \binom { i } { j } }
$$

反演公式成立。
