## Slide 2: 圆方树的原理和相关题目

- 圆方树，block cut tree，代表原图的点和点双连通分量的关系
- Tarjan算法求解点双连通分量的过程，可以用来建立圆方树
- 圆方树的性质
- 1，原图的点为圆点，点双连通分量为方点
- 2，节点数量为n，圆点编号 <= n，方点编号 > n
- 3，圆方树中的圆点和方点交替出现，圆点的邻居都是方点，方点的邻居都是圆点
- 4，圆点的每个邻居都是当前点所归属的点双连通分量
- 5，方点的每个邻居都是当前点双连通分量所拥有的点
- 6，圆点只有一个邻居，该点不是割点，多于一个邻居，该点是割点
- 7，原图中任意两点之间的必经点 = 圆方树简单路径中的圆点
- 8，一个点双连通分量的子图内，任意三点a、b、c，存在a到b，然后b到c的路径，沿途节点不重复

## Slide 10: 圆方树的原理和相关题目

- 题目8
- 游客
- 一共n个城市、m条双向道路，所有城市都连通，商品只有一种
- 每个城市给定商品报价，接下来有q条操作，操作类型有两种
- 操作 C x y : 城市x的商品报价改成y
- 操作 A x y : 从x到y可自由选路，但不能有重复城市，打印能遇到的最低报价
- 1 <= n、m、q <= 10^5
- 1 <= 商品报价 <= 10^9
- 测试链接 : https://www.luogu.com.cn/problem/CF487E
- 测试链接 : https://codeforces.com/problemset/problem/487/E
- 圆方树 + 树链剖分 + 重链用线段树维护最小值
- 方点用有序表收集点权，圆点修改点权之后，也修改父亲方点中的点权
- 查询时，如果lca为方点，需要额外再查一下父节点圆点的点权

## Slide 11: 圆方树的原理和相关题目

- 题目9
- 战略游戏
- 给定一张无向图，一共n个点、m条边，所有点保证连通，图中可能有重边
- 一共有q条查询，每条查询格式 s K1 K2 .. Ks，含义如下
- 当前查询涉及s个点，给出s个点的编号，你只能删掉一个另外的点
- 删除该点后，只要这s个点中存在任意两点不连通，就算成功
- 对每条查询，打印你能选择的点的个数
- 2 <= n <= 10^5 1 <= m <= 2 * 10^5 1 <= q <= 10^5
- 所有查询中s的总和 <= 2 * 10^5
- 测试链接 : https://www.luogu.com.cn/problem/P4606
- 讲解180，虚树，题目6，寻宝游戏
- 关键节点按dfn排序，相邻两点之间边的数量 + 首尾两点之间边的数量 = 虚树上边的数量 * 2
- 注意边有这个性质，但是点没有，所以本题需要转化，然后使用边差分

- 左程云
