卡特兰数的取模处理

求解卡特兰数第n项，答案对p取模，有如下几种数据状况

情况1， $\mathsf { n }$ 是 $< = 3 5$ 规模，答案不会溢出long类型的范围，往往不取模就返回真实值，使用：公式4  
情况2， $\mathsf { n }$ 是 $1 0 \land 3$ 规模，p为质数，使用：公式1、公式2、公式3、公式4  
情况3， $\mathsf { n }$ 是 $1 0 \land 3$ 规模，p可能是质数也可能是合数，使用：公式4  
情况4， $\mathsf { n }$ 是 $1 0 \land 6$ 规模，p为质数，使用：公式1、公式2、公式3  
情况5， $\mathsf { n }$ 是 $1 0 \land 6$ 规模，p可能是质数也可能是合数，使用：公式2 $^ +$ 因子计数法
